# رِواق — interactive law firm demo

Arabic-first RTL React + TypeScript + Vite demo. Fictional brand; no backend or real contact submission.

## Run

```powershell
cd D:\mostqel\3D
npm install
npm run dev
```

Preview: http://localhost:5173/

```powershell
npm run build
npm run preview
```

## Experience

- Procedural Three.js scales with turned pillar, sculpted crossbar, instanced chain links, hanging bowls and veined stone pedestal.
- Damped pointer rotation and balancing; GSAP ScrollTrigger controls sculpture rotation, camera progression, reveals and approach progression.
- Locally hosted Al Mohanad font supplied by the user, in `public/fonts/al-mohanad.ttf`.
- Six expandable practice areas, responsive navigation, accessible local form validation and explicit demo success state.
- Reduced-motion support, WebGL error fallback, capped pixel ratio and offscreen render suspension.
- No external model, image, environment-map or font requests.

The large lazy-loaded 3D bundle is expected for Three.js. WebGL performance depends on the device. The contact form does not transmit, save data or book appointments.
